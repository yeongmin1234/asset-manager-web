# 예비 SCM 화면 미리보기

바탕화면의 `예비 SCM (장기프로젝트)/frontend/src`를 복사한 화면 스냅샷입니다.
현재 홈페이지의 관리자 메뉴 `/admin/scm-preview`에서 iframe으로 표시합니다.

- 화면은 샘플 사용자와 샘플 데이터로만 표시합니다.
- CSP가 네트워크 요청을 차단하므로 예비 SCM 백엔드, DB, SCM 서버에 연결하지 않습니다.
- 내부 이동은 iframe의 해시 경로를 사용해 현재 홈페이지 라우팅과 충돌하지 않습니다.
- 원본 프로젝트와 자동 동기화되지 않습니다. 화면을 갱신할 때는 원본 변경사항을 검토한 뒤 이 복사본에 반영합니다.
- `npm run build`가 미리보기 정적 파일을 먼저 만들고 기존 홈페이지 번들을 빌드합니다.

정적 번들은 URL을 아는 사람이 직접 열 수 있으므로 실제 고객 데이터나 운영 기능을 여기에 추가하지 않습니다.
