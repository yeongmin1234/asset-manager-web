# SCM 프론트 화면 복사본

바탕화면의 `예비 SCM (장기프로젝트)/frontend/src`를 복사한 화면 스냅샷입니다.
현재 홈페이지의 `/scm-app`에서 별도 SCM 레이아웃으로 표시합니다. 관리자 또는 `scm_app` 메뉴 권한 사용자만 진입할 수 있습니다. 기존 운영 SCM 관리 화면 `/scm`은 그대로 둡니다.

- 화면은 샘플 사용자와 샘플 데이터로만 표시합니다.
- CSP가 네트워크 요청을 차단하므로 예비 SCM 백엔드, DB, SCM 서버에 연결하지 않습니다.
- 내부 이동은 프레임의 해시 경로를 사용하며, 부모 앱은 이를 `/scm-app/...` 주소에 반영합니다.
- 원본 프로젝트와 자동 동기화되지 않습니다. 화면을 갱신할 때는 원본 변경사항을 검토한 뒤 이 복사본에 반영합니다.
- `npm run build`가 SCM 정적 파일을 먼저 만들고 기존 홈페이지 번들을 빌드합니다.

정적 문서를 단독으로 열면 인증된 `/scm-app`으로 이동합니다. 이 클라이언트 측 이동은 서버 접근 통제를 대신하지 않습니다. 실제 고객 데이터나 운영 기능을 연결하기 전에는 정적 파일 제공 경로에도 서버 측 인증이 필요합니다.
