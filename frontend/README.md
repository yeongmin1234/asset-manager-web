# Frontend

React + Vite 기반 자산관리 프론트엔드입니다. 자산 목록 조회, 필터, 신규 자산 등록, 상세 보기 모달, 수정, 폐기/삭제, 변경 이력 화면을 제공합니다.

화면은 흰색/연회색/파란색 중심의 업무용 SaaS 대시보드 톤으로 구성하며, PC/노트북에서는 넓은 테이블과 통계 카드 배치를 사용하고 모바일에서는 1열 카드형 목록으로 전환합니다.

현재 구현 화면:

- Backend 연결 상태 확인
- 자산 현황 요약 카드
- 분류별/부서별 자산 통계
- 최근 3개월 월별 등록/폐기 추이
- 자산 빠른 등록 카드
- 자산 목록
- 검색어, 상태, 분류, 부서 필터
- 필터 초기화와 목록 새로고침
- 제품명, 상태, 사용자, 시리얼번호 프론트 정렬
- 빠른 등록의 제품명/분류/부서(사용자명)/상태/시리얼번호/메모 입력
- 자산 등록 모달
- 자산 상세보기 모달
- 자산 수정 모달
- 자산 폐기 처리 버튼
- 자산 삭제 버튼
- 자산 변경 이력 섹션

아직 구현하지 않은 화면:

- 로그인/권한관리
- 엑셀/QR/사진 업로드

## 개발 실행

```bash
cd frontend
npm install
npm run dev
```

Backend가 `http://127.0.0.1:8001`에서 실행 중일 때 함께 확인합니다. 로컬 DB, migration, seed, API 검증 순서는 `../docs/LOCAL_DB_SETUP.md`를 참고하세요.

확인 URL:

- http://127.0.0.1:5173/

API 주소는 `.env`의 `VITE_API_BASE_URL`로 설정하며, 예시는 `.env.example`에 있습니다.
별도 설정이 없으면 `http://127.0.0.1:8001`을 사용합니다.

Backend 또는 PostgreSQL이 꺼져 있으면 목록/상세/이력/선택값/처리 API가 오류를 반환할 수 있습니다. 이 경우 화면은 깨지지 않고 사용자가 이해할 수 있는 오류 안내를 표시합니다.

통계 화면은 `GET /stats/summary`, `GET /stats/by-category`, `GET /stats/by-department`, `GET /stats/monthly`를 사용합니다. 요약 카드는 전체/사용중/미사용/폐기만 표시하고, 월별 등록/폐기 추이는 최근 3개월만 표시합니다. 빠른 등록과 상세 등록은 같은 자산 생성 API를 사용하며, 등록/수정/폐기/삭제 후 목록과 통계를 다시 불러옵니다. 통계 API 실패 시 해당 통계 영역에만 오류를 표시합니다.

## 포트 기준

- Frontend 개발 서버: `5173`
- Frontend 배포 외부 포트: `3010`
- Backend 개발 API 주소: `http://127.0.0.1:8001`
- 포트 `80`, `8080`은 SCM 또는 NAS 내부 서비스와 충돌할 수 있으므로 사용하지 않습니다.

## NAS 직접 실행 기준

운영 NAS에서는 개발 서버를 실행하지 않고 정적 빌드 결과만 제공합니다.

```bash
cd frontend
npm install
npm run build
```

기본 운영 후보는 `frontend/dist`를 `3010` 포트의 정적 서버로 제공하는 방식입니다. 운영 API 주소는 빌드 전에 `VITE_API_BASE_URL=http://192.168.222.210:8001`처럼 지정합니다.
