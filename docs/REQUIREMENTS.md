# Requirements

현재까지 확정된 자산관리 기준입니다. 이번 작업에서는 기능을 구현하지 않고 문서로만 정리합니다.

## 자산관리 대상

자산관리 대상은 주로 전자제품입니다.

예시:

- 노트북
- 데스크탑
- 모니터
- 프린터
- 태블릿
- 휴대폰
- 키보드
- 마우스
- 충전기
- 허브
- 네트워크장비
- 기타 전자기기

## 상태값

- 사용중
- 미사용
- 폐기

`미사용`은 창고 보관 중인 자산이며 폐기가 아닙니다. `폐기`는 실제로 더 이상 사용하지 않는 자산입니다.

## 데이터 관리 기준

- 삭제는 잘못 입력한 데이터 제거용
- 시리얼번호는 입력 시 영어 대문자 `A-Z`와 숫자 `0-9`만 허용 예정
- 소문자 입력 시 대문자로 변환 예정
- 한글, 공백, 특수문자는 시리얼번호에 허용하지 않음
- 중복 시리얼번호 등록 방지 예정
- 변경 이력 기록 예정
- 통계 화면 예정
- 엑셀 내보내기 예정

## DB 설계 기준

- `assets`는 자산 본체 테이블
- `asset_history`는 자산 변경 이력 테이블
- `categories`는 자산 분류 테이블
- `departments`는 사용 부서 테이블
- 실제 운영 DB 테이블 생성은 마이그레이션 단계에서 진행 예정
- 기존 SCM MySQL DB와 연결하지 않음
- 자산관리 전용 PostgreSQL을 별도 운영

## 이번 단계 제외 범위

- 자산 CRUD API
- 실제 운영 DB 테이블 생성
- 로그인 및 권한관리
- QR/바코드 기능
- 엑셀 내보내기 기능
