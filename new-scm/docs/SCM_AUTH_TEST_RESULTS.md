2026-10-27, 개발 환경. 실제 사용자 비밀번호·토큰·DB 행은 사용하지 않았다.

## 실행

- `new-scm/backend`: `python -m unittest discover -s tests -v` → **12개 통과** (기존 4개, 신규 인증 경계 8개).
- `new-scm/frontend`: `npm run build` → 성공.
- `new-scm`: `python scripts/generate_auth_matrix.py` → 표시 메뉴 39개, 설계 API 115개 매핑 생성.

## 확인된 경계

| 항목 | 결과 | 범위 |
|---|---|---|
| 미인증 `/api/v1/auth/me` | 401 | TestClient |
| 미구현 업무 경로 `/api/v1/users` | 미인증 401, 테스트 주입 인증 후 404 | 실제 업무 응답 없음 |
| 임의·만료 가정 Bearer 값 | 401 | 실제 기존 JWT가 아닌 더미 문자열; 검증기 미연결 상태 |
| 임의 `X-User-Id`/`X-Role` | 401 | 헤더만으로 사용자 식별 불가 |
| 검증기 통신 오류 | 401 | 테스트 검증기 예외 주입; 응답에 자격정보/오류 상세 없음 |
| 비활성 검증 주체 | 401 | 테스트 검증기 주입 |
| 검증된 주체이나 `system.access` 없음 | 403 | 테스트 검증기 주입 |
| 메뉴·행위·관리자 조건 부족 | 403 | 권한 함수 단위 테스트 |
| 프론트엔드 메뉴·행위 표시 | 명시적 `system.access` 및 경로/행위 grant 필요 | 실제 로그인 주체가 없어 화면 진입은 계속 차단; 빌드 확인 |
| 검증된 주체 + 명시적 시스템 grant | 200 | 테스트 검증기 주입만; 실제 로그인 연동 아님 |
| `/health`, 상태 API, 진단 키 거부 | 200/200/403 | 기존 공개·진단 정책 유지 |

## 미검증·미구현

- 실제 기존 로그인 사용자의 독립 SCM 진입, 원본 토큰 교환, 인증 유지/갱신/로그아웃 동기화: **미구현·미검증**.
- 실제 위조/만료 JWT 서명 검증: **미구현**. 현재 검증기 미연결이라 어떤 Bearer 값도 401이다.
- 신규 SCM DB의 실제 사용자 조회·외부 주체 매핑·권한 데이터 저장: **미구현**. DB 접속/행 조회/변경을 수행하지 않았다.
- 업무 API 115개의 엔드포인트별 401/403, 매장·행·필드 범위, 관리자/승인자/업로드/일괄 변경: **업무 라우트 0개로 미검증**.
- 기존 자산관리 앱의 iframe 미리보기는 수정하지 않아 그 화면의 Mock 권한은 그대로다. 독립 SCM 프론트엔드 차단은 빌드로 확인했고 실제 브라우저 화면 검증은 수행하지 않았다.
- 보호 포트/서비스 재시작, 운영 NAS 배포, DB 마이그레이션, 쓰기 권한 추가: 수행하지 않았다.
